# 0.6.1 · 模型一致性与服务器入口

服务端和客户端同步更新至 0.6.1。

- 本地、私人分享与服务器接管共用 BBModel 解码和 profile；保留完整运行资产，修正作者静态骨骼及 4.x／5.x 动画轴向、Molang 程序、曲线和物理推进。同文件在相同姿态、参数与动作输入下采用同一解释规则。
- 服务器卡片复用云朵，分别显示已缓存、内存已就绪、待缓存、处理中、不可用与未知；预览和提示明确资源来源、准备阶段及接管是否启动。
- 未配置名称的服务器动作显示作者 ID，轮盘与聊天不再混为“自定义动作”；整理服务器消息的分行与引导。
- 服务器伪装、模型目录与命令补全来自 ME 注册表。移除 MPA 模型配置白名单依赖；缺少 MPA 客户端原模型或可选内置模板不阻止有效 ME 模型伪装。客户端资源不可用时保持服务器显示。

服务器伪装与本地／私人分享仍互斥，权限、观看许可、资源预算及接管确认继续生效。完整传输不会还原源文件已烘焙丢失的作者公式，服务器需提供完整原文件。

本轮使用新增或受影响的定向检查，最终构建不重复执行已完成场景；画面及多人行为由用户自行测试。当前操作见[客户端配置](../CLIENT_CONFIG.md)，部署职责见[模型同步](../MODEL_DELIVERY.md)，实现规则见[YSM 支持范围](../YSM_COMPATIBILITY.md)。
