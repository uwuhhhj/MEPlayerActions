# 0.6.1 · 模型一致性与服务器入口

服务端和客户端同步更新至 0.6.1。

- 本地、私人分享与服务器接管共用 BBModel 解码和 profile；保留完整运行资产，修正作者静态骨骼及 4.x／5.x 动画轴向、Molang 程序、曲线和物理推进。同文件在相同姿态、参数与动作输入下采用同一解释规则。
- 服务器卡片复用云朵，分别显示已缓存、内存已就绪、待缓存、处理中、不可用与未知；预览和提示明确资源来源、准备阶段及接管是否启动。
- 未配置名称的服务器动作显示作者 ID，轮盘与聊天不再混为“自定义动作”；整理服务器消息的分行与引导。
- 服务器伪装、模型目录与命令补全来自 ME 注册表。移除 MPA 模型配置白名单依赖；缺少 MPA 客户端原模型或可选内置模板不阻止有效 ME 模型伪装。客户端资源不可用时保持服务器显示。
- 客户端资源只从管理员显式发布的 MPA `models/` 下发，不自动回退内置文件或 ME 蓝图。服务器图库按来源与子文件夹隔离，MPA 优先，根文件归“未分类”，历史缓存独立浏览。
- 修正本人接管服务器伪装后消失：区分 ME 隐藏原版外观的元数据标记与玩家真实隐身，仅有效接管绑定使用服务器真实状态，保留隐身、发光轮廓及本人显隐选择。
- 修正 BBModel 六个 cube 面的贴图角点和绕序，解决眼睛、裙摆等纹理上下／左右方向异常；保留作者的反向 UV 与面旋转，不给缺失、空贴图或禁用面补画。同一导入修复覆盖本人及其他观看者，重启更新后的客户端会重新解释原始缓存。
- 私人分享协商观看端的渲染开关，关闭时暂停接收与准备回执，重新开启可重新授权；保持旧端能力回退与权限检查。服务器 `status player` 区分本人发布、观看对象、传送阶段、资源 READY 和失败，不将准备回执误说成当前已绘制。
- 增加独立的私人分享缓存入口，展示接收来源、进度与历史资源，只读预览完整资源包；本人上传管理仍走原云朵入口。客户端状态与诊断补齐接收阶段、缓存验证和本机失败原因。
- 补齐已上传模型的存档管理：使用当前服务器已保存且本机匹配的模型直接恢复分享；云朵也可再次分享、单独结束分享或删除存档。重新检查目录身份、文件内容和权限，旧确认不能停止新发布；明确重试可解除先前发布失败的阻塞，自动重试预算保持。

服务器伪装与本地／私人分享仍互斥，权限、观看许可、资源预算及接管确认继续生效。完整传输不会还原源文件已烘焙丢失的作者公式，服务器需提供完整原文件。

本轮使用新增或受影响的定向检查，最终构建不重复执行已完成场景；画面及多人行为由用户自行测试。当前操作见[客户端配置](../CLIENT_CONFIG.md)，部署职责见[模型同步](../MODEL_DELIVERY.md)，实现规则见[YSM 支持范围](../YSM_COMPATIBILITY.md)。
