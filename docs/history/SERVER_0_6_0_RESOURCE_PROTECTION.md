# 0.6.0 · 服务器资源保护

[更新日志](README.md) · [当前资源保护说明](../SERVER_RESOURCE_PROTECTION.md)

此版本处理 [Issue #1](https://github.com/uwuhhhj/MEPlayerActions/issues/1)，服务端与客户端同步更新为 0.6.0。

- 模型读写、校验与资源准备采用共享固定线程池、有界等待和主线程提交队列，增加全局／玩家任务与字节预留、分阶段超时、协作取消及迟到结果检查。
- 服务器原生动画模板首次读取、解析与纯表达式编译也移入后台，未准备时保留旧外观并提示稍后重试；解析模板与网络压缩／预编码内容共用缓存字节和条目预算，原始准备输入纳入作业预留。
- 服务器模型与私人资源共享可配置上下行、包数、并发、等待传输和待发送字节预算；预算耗尽先暂停推进，避免反复创建同一分片。支持的客户端通过服务器额度窗口发送私人上传分片。
- 添加 TPS／MSPT 及插件资源压力保护，逐级减速、暂停新增和分批清理自有展示；健康持续一段时间后逐级恢复，必要撤销与确认保持运行。
- 全服伪装、私人发布、观看关系、每观看者模型及新建／切换频率有共享上限；模型增加整体复杂度预算，私人缓存写入检查磁盘水位与临时文件额度。
- `/meplayeractions status` 显示全服健康快照；`network`、`tasks`、`models`、`protection` 分类查看，`player <玩家名>` 保留个人排查入口。
- 资源失败增加阶段、可重试与等待提示；私人上传限制自动重试次数和总时间，不对无效资源无限重传。

升级保留原配置，缺少的 `resource-protection` 字段采用默认值。三条渲染路径、原版位置同步和独立权限保持原有分工，网络资源仍走 Plugin Message。构建与定向检查证据随本版交付保存；没有千人容量、TPS 或游戏画面的实测结论。
