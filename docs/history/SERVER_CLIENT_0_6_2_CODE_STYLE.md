# 0.6.2 · 代码规范与可读性整理

服务端与客户端同步更新至 **0.6.2**。

- 新增项目 `AGENTS.md`，明确显式类型、控制语句大括号、实例字段限定、注释、嵌套三元表达式、反射缓存及方法划分要求。
- 整理两端生产代码和测试：替换 `var`、补齐控制语句大括号、左大括号与声明或控制条件同行、块内逻辑从下一行开始、方法间保留空行、限定实例字段并为嵌套三元表达式加括号。
- 提供可导入 IDE 的 Java 格式配置；保留第三方版权和来源说明。
- 精简内部模板和资产缓存、皮肤及配置查询中的 `Optional`；保留已有缺失值处理和必要 API 契约。可选 ModelEngine 后端的构造器在首次解析后缓存，重载时复用；已有 GSit 和原生数据包反射缓存继续使用。
- 同步更新构建、版本说明与打包合同，源码包包含协作规范和格式配置。
- 发布后修正左大括号的位置并保持版本为 `0.6.2`；Release 中的 `brace-fix` 附件包含修正后的构建、源码和验证记录，原标签与历史附件保留。
- 用修改前的源码独立复现并修正两处旧测试预期：第一人称组件核对来源文件的八个 parallel 动画；逐行时间线用例显式关闭多行合并。模型导入行为保持现有契约。

当轮编译、单元检查及安装包校验结果随交付保存。单元检查不代表 Minecraft、服务器画面或多人性能实测。
