# 0.5.1：上游运行时与统一图库

[更新日志](README.md) · [当前客户端使用](../CLIENT_CONFIG.md) · [YSM 兼容范围](../YSM_COMPATIBILITY.md)

- 修正 YSM 头部查询角度；本地、私人分享和服务器接管均复用原版玩家当帧渲染位置，避免重新计算位置造成显示跳动。私人飞行展示使用服务器确认的状态。
- 迁移固定 OpenYSM／Sparkle 源码的骨骼通道过渡、控制器求值顺序、脚本合并、声音生命周期和原版渲染语义。
- 本地与私人 BBModel 复用 Sparkle 的完整解析、转换与装配链，包括独立骨架、网格、挂点、数值曲线、控制器和伴随 PNG；原生附件沿来源指定链绘制。
- 图库采用上游居中面板；“客户端／服务端”共用 5×2 布局、搜索、收藏与分页。服务端目录由服务器主动提供，“使用模型”发送伪装命令并由服务器校验。
- 客户端卡片增加云朵“上传分享”和“已上传”筛选。使用模型保持仅本机显示；上传分享须显式操作、服务器启用及权限允许，只有服务器确认后才标记已上传。
- 私人观看者复用原版同步字段或缺省值；不新增食物、经验、完整效果或按键输入同步，远端食物值回退为 20。

构建与检查证据随对应交付保存。游戏画面与多人场景由玩家验收，未进行千人性能压测。
