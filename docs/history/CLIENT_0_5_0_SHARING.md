# 0.5.0：私人上传与三条渲染路径

[版本历史](README.md) · [当前安装](../../README.md) · [模型部署](../MODEL_DELIVERY.md) · [客户端配置](../CLIENT_CONFIG.md) · [协议](../CLIENT_PROTOCOL.md)

## 行为

- 本地私人外观默认只供本人观看，选用模型不上传。
- 私人多人分享由发布者显式开启，服务器与上传／观看权限同时允许后，上传完整原生 YSM 或 BBModel bundle；获准模组观看者在本机渲染，原版观看者继续看到原版人物。
- 服务器 ME 伪装保持独立：服务器决定模型与绑定，模组观看者按授权接管，其他观看者由 ME 显示。本人手动 CLIENT 覆盖不自动分享。

私人分享不依赖 ModelEngine，不自动创建蓝图、公开模型目录或原版资源包。现有模型格式、作者配置、控制器、表达式和本地原版动作沿用既有完整资源流程，没有替换为单一转换模型。

## 上传、缓存与恢复

服务器新增按上传者 UUID 和完整资源 hash 隔离的私人磁盘缓存，默认 128 MiB、512 个条目、每上传者 4 项。同上传者再次选择可在后台重新验证后免重传；未知 hash 或其他上传者不能索取缓存。现有接收／展开内存预算与有界校验并发继续生效。

关闭分享、离线、撤权和租约到期结束当前发布，保留有界资源缓存。重启不自动恢复旧发布。权限随连接状态刷新；受出站预算影响的私人状态、资源反馈和就绪确认使用身份受限的恢复流程，不能扩大观看资格。

上传提案和完成通知按秒重试至对应确认，同上传身份不重启校验、重置分片或延长时限。观看端 missing 等待 asset_begin，cached 与 ready 等待精确 private_ack，本机发送成功不能替代服务器确认。上述控制共用每秒 16 包、突发 8 包的客户端预算，资产分片仍每 tick 推进。publisher 每两秒重发当前参数状态；服务器将相同状态幂等续租，不递增动作序号或重播。

## 兼容与验证

服务器伪装仍为 `meplayeractions:main` v3，私人分享仍为独立 `meplayeractions:private` v1。它们与原 OpenYSM／Freesia 网络协议不互通。新增协商字段按本版协议说明解析；旧配置保持私人分享关闭。

本版定向单元与组件检查共 106 项通过：服务端 70 项、客户端 36 项，含屏蔽全部 ModelEngine 类后的入口与私人策略隔离检查。Windows 未允许创建符号链接，存储测试的附加符号链接分支未执行；实际文件／目录占位拒绝检查已通过，阶段证据保留此限制。

两端构建、安装包与源码一致性结果由交付的 tests ZIP／build JSON 记录。未启动游戏或进行千人在线性能压测，保留用户自行测试的流程。历史包不覆盖。
