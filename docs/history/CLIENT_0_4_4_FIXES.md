# 客户端 0.4.4 修复说明

[安装和使用](../../README.md) · [客户端配置](../CLIENT_CONFIG.md) · [YSM 兼容范围](../YSM_COMPATIBILITY.md) · [架构](../../ARCHITECTURE.md)

本次交付为 **Fabric 客户端 0.4.4**，配套服务器继续使用 **MEPlayerActions 0.4.3**。服务端源码、版本和协议不变；这是客户端修复包。

## 升级安装

1. 退出 Minecraft，移除当前游戏实例 `mods/` 中旧的 MEPlayerActions 客户端 JAR。
2. 将修复包中的 `MEPlayerActions-Client-0.4.4.jar` 放入该实例 `mods/`，保留已有 Fabric Loader、Fabric API 和其他正常依赖后重启。目标仍是 Minecraft 1.21.11／Java 21。
3. 保留 `config/meplayeractions-client.json` 和私人模型目录，已有有效设置继续读取。已运行 0.4.3 的服务器无需替换插件 JAR、配置或重新导入蓝图。

0.4.4 新增 `hideVanillaPlayer=true`、`hideVanillaEquipment=true`，与 `showSelf=true` 分别控制原版人物、原版装备、本人伪装。首次读取两个新字段均缺失的旧配置时，将 `showSelf` 迁移为 `true`，避免旧“本人隐藏”使伪装消失；已有任一新字段时保留明确保存的伪装显隐。新人物／装备字段各自缺省为隐藏，三个显隐互不联动。

同一游戏实例只保留一份 MEPlayerActions 客户端 JAR。只用 CLIENT 私人外观时仍无需服务器插件；SERVER 功能需要服务器当前授权和同步。

## 本次八项修正

1. **服务器与常规 BBModel GUI 预览保留真实深度。** 原来的二维面平均排序路径改为复用现有原生 RGBA8／DEPTH32 离屏附件、逐顶点深度、LEQUAL 和深度写入。服务器／常规 BBModel 继续使用单位作者比例与边界自动取景；私人 YSM 的 INITIAL 作者比例不套用到它们。半透明面仍按提交次序混合并写深度，不保证任意相交半透明面的排序。
2. **图库卡片恢复 OpenYSM 的固定尺寸。** 卡片为 52×90 像素，横／纵步长为 55／93，足够空间时五列两行；窄窗口减少列／行数，卡片不随窗口拉宽。名称在 45 像素内折行，最多两行居中。YSM 作者背景／前景覆盖完整 90 像素卡片，模型以 76 像素视口提交、仅模型裁切到 70 像素，装饰与名称区域各按原有层次绘制。
3. **第一人称手臂使用上游完整作者坐标与左右遮罩。** 使用 `T(左 +0.25／右 -0.25, 1.8, 0) S(-1, -1, 1)`，去掉肩部归一化及额外 BODY／用户比例。左右手骨骼遮罩按作者骨骼层级继承。只接管原生空手或地图调用左右手绘制入口的路径；删除普通持物路径额外插臂的 Mixin，方块、武器和物品使用继续走原版持物变换，不承诺这些路径额外显示作者手臂。
4. **主页与详情预览的上下拖动方向统一。** 两处遵循上游 `pitch -= dy`，左右继续 `yaw += 1.5 × dx`，俯仰限制为 `-90°–90°`。
5. **关闭渲染后保留 SERVER 动作轮盘。** 顶层 `enabled` 只控制本地绘制、模型效果和显示接管。关闭时对已 ready 绑定发送 `render_failed`，释放 GPU／显示租约并由 ME 恢复显示；有效服务器连接、当前绑定的动作目录、状态与心跳继续维护。J 的 SERVER 播放和中心 stop 不依赖本地模型 GPU 准备或显示租约；播放 ID 必须来自当前服务器目录，断线、解绑或状态超时不使用旧动作。释放租约引起的正常短暂解绑仍等待服务器下一次同步恢复当前目录。关闭期间可继续接收已授权模型，但不发送 `render_ready` 或建立本地接管。
6. **主页三个显隐按钮直接显示状态。** 页脚常驻“玩家隐藏／玩家显示”“装备隐藏／装备显示”“伪装显示／伪装隐藏”三个独立 44 像素按钮，选中底色读取各自真实字段，点击立即保存并刷新。详情的三个显隐是独立草稿，保存时分别应用；“保存并预览”明确开启伪装显示。渲染／接管总开关移入页脚齿轮的客户端设置，也可用 `/mpaclient toggle`，不常驻为第四个显隐按钮。
7. **人物、装备与伪装模型三层独立。** CLIENT 私人外观默认隐藏原版人物和原版盔甲／披风／鞘翅、显示伪装。玩家显示而装备隐藏时，仅抑制原版装备渲染层；玩家隐藏而装备显示时，按模型可用挂点绘制一套装备；伪装隐藏不会关闭已明确显示的装备。主副手物品及真实库存不改动，作者自带衣物、帽子等几何属于伪装，不受原版装备开关影响。本人服务器伪装存在时，玩家／装备按服务器规则显示强制隐藏并禁用，伪装仍可控制本机自显，不影响已有手动 CLIENT 覆盖或服务器观看许可。伪装隐藏也停止作者第一人称手臂；玩家显示时回到原版手臂，玩家隐藏时取消该手臂入口，普通持物路径保留。关闭总渲染则退出本地接管并恢复 ME／原版显示，三个显隐设置保留。
8. **J 轮盘与鼠标中心对齐并显示滚轮说明。** 轮盘中心使用实际屏幕 `width/2, height/2`，不移动鼠标；右侧分类、分页、返回及配置面板随轮盘布局移动，窄屏按可用空间缩放。普通区域滚轮上滚上一页、下滚下一页，按真实页数限制；配置已打开且鼠标位于右侧面板起点或更右时，上滚／下滚改为滚动配置。底部随页数和配置状态显示对应操作提示。右上角使用既有 `settings.png` 齿轮进入统一 `PlayerModelScreen`，默认快捷键仍只有 J。

## 源码参考与边界

GUI 和第一人称适配继续以 [OpenYSM-Updated 固定提交](https://github.com/IzumiiKonata/OpenYSM-Updated/tree/0306e1fa3bbeaaf6fa8c1af89d87bb7a1c077b85) 为依据。卡片参考 `ModelButton`，拖动参考 `PlayerModelScreen`／`PlayerTextureScreen`，第一人称基准参考 `HandItemRenderer` 和原生手臂入口。页脚状态反馈参考上游布尔控件的真实状态绘制。来源与许可见 [第三方说明](../../THIRD_PARTY_NOTICES.md)。

这些是针对当前源码的修正，不代表复制完整 OpenYSM 渲染器、兼容层或网络协议。GUI 手持物品几何绘制、加密 `.ysm`、网格绑定及外部模组动画族仍在既有边界之外。

## 验证范围

本次按要求仅进行 **客户端 `build -x test` 编译与修复包内容／完整性校验**。**未运行单元测试、Minecraft、A/B 或独立客户端实机场景**；本次八项修复的画面与交互效果由用户安装此 JAR 后实机验证。编译及包校验的结果以随本次交付的构建／打包记录为准。

0.4.3 的 78 项定向客户端单元测试，以及实机 A／B／独立客户端的 73／38／25 项检查，仍是 **0.4.3 的历史结果**，不是 0.4.4 的重跑、实测或通过证明。0.4.2 的完整测试、截图和报告同样保留为历史，详见 [历史验证范围](README.md#早期记录与证据范围)。
