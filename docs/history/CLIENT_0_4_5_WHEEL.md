# 客户端 0.4.5 轮盘解除伪装说明

[安装和使用](../../README.md) · [客户端配置](../CLIENT_CONFIG.md) · [YSM 兼容范围](../YSM_COMPATIBILITY.md) · [0.4.4 历史修复](CLIENT_0_4_4_FIXES.md)

本次交付为 **Fabric 客户端 0.4.5**，服务器继续使用 **MEPlayerActions 0.4.3**。0.4.5 在 J 轮盘左侧新增与右侧一致的平面模块，按当前 CLIENT／SERVER 来源提供解除入口；中心动作控制、滚轮翻页与右侧作者配置沿用既有行为。

## 升级安装

1. 退出 Minecraft，移除当前游戏实例 `mods/` 中旧的 MEPlayerActions 客户端 JAR。
2. 将包内 `MEPlayerActions-Client-0.4.5.jar` 放入该实例 `mods/` 后重启，同一实例只保留一份本模组。目标仍是 Minecraft 1.21.11／Java 21，Fabric Loader 与 Fabric API 要求沿用原安装说明。
3. 保留 `config/meplayeractions-client.json`、私人模型、皮肤与作者配置。已有 0.4.3 服务器无需替换插件 JAR、配置或蓝图；服务端源码、版本和协议未修改。

## J 轮盘左侧解除入口

| 当前来源 | 按钮 | 行为 |
| --- | --- | --- |
| SERVER | 解除服务器伪装 | 有服务器连接、玩家／网络及已知本人服务器伪装时，发送固定 `/meplayeractions undisguise` 请求，由原服务端命令检查权限和本人会话。 |
| CLIENT | 解除私人伪装 | 当前私人外观已启用且可编辑时，仅将 `localAppearance.enabled` 关闭；模型、缩放／XYZ、皮肤、作者配置与其他设置保留，不发送服务器命令。 |

SERVER 请求发送后显示“已请求解除服务器伪装，等待服务器确认”，客户端不提前清除绑定、不伪造解除成功，也不自行切到 CLIENT。以服务器命令反馈和后续状态／解绑确认为准；无权限或被拒绝时，服务器伪装仍按服务器实际状态处理。若 MPA 只是接管外部插件创建的原生模型，原命令只停止 MPA 接管，真实原生模型仍需由其原插件解除。

CLIENT 在没有服务器伪装时恢复原版外观；手动 CLIENT 覆盖本人服务器伪装时，只停用私人外观并切回 SERVER 来源，保留服务器伪装，然后返回此前画面。重新选用私人模型可继续使用保存的参数。轮盘中心的 SERVER stop 仍只停止手动动作，解除整个伪装使用左侧按钮。

关闭客户端渲染后，这两类解除仍可使用：SERVER 入口不依赖 GPU、临时绑定或 ready／ACK；CLIENT 入口仍可保存私人停用状态。断线或没有本人服务器伪装时，SERVER 入口不可用；私人外观未启用时，CLIENT 入口不可用。按钮始终按当前来源处理，不增加额外冷却或权限。
