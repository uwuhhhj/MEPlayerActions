## 早期记录与证据范围

0.4.2 的独立客户端实机记录覆盖作者预览、配置保存、第一人称手臂、部分原版组件和本地声音／粒子的播放与清理，不代表所有作者模型或多人场景已验证。

0.4.3 使用历史 `interactions` 发布检查；当时的客户端定向单元与交互实机证据属于该版。0.4.2 服务端测试仅在源码、资源和 JAR 行为字节一致证明通过后复用。详细数量以对应版本 tests ZIP／验证 JSON 为准。

0.4.4 的八项修复与 0.4.5 的解除入口只做编译／包校验。0.4.6、0.4.7 做新增或受影响的定向单元、编译和包校验，未启动游戏实机复验。

0.4.8 有 21 项定向单元通过，用户原文件完整离线导入及预览网格采样成功，原始 SHA-256 不变；沿用 0.4.7 服务端，未生成新服务端包，未启动游戏或服务器。

0.4.9 两端定向单元共 277 项通过（服务端 247、客户端 30），两端编译和包校验通过；没有游戏实机或千人性能压测。本次仓库／文档整理没有新增游戏验证或改变运行版本。

当前行为与限制见[客户端配置](../CLIENT_CONFIG.md)、[YSM 兼容范围](../YSM_COMPATIBILITY.md)和[性能配置](../PERFORMANCE.md)。
