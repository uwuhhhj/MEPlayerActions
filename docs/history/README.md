## 早期变更

0.4.2 引入独立客户端的作者预览、配置保存、第一人称手臂、原版组件与本地声音／粒子。0.4.3 补充原始酒狐模型及上游图库、轮盘和持物能力。

界面入口统一为 J 轮盘与设置主页，移除 G／Y／N 入口，旧 G 绑定不沿用；玩家、装备和伪装显隐改为三个独立按钮，总渲染开关移入设置。

当前行为与限制见[客户端配置](../CLIENT_CONFIG.md)、[YSM 兼容范围](../YSM_COMPATIBILITY.md)和[性能配置](../PERFORMANCE.md)。
