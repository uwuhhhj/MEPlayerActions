# 客户端配置与使用

[文档索引](README.md) · [安装](../README.md) · [服务器模型与部署](MODEL_DELIVERY.md) · [YSM 支持范围](YSM_COMPATIBILITY.md) · [开发导航](../CONTRIBUTING.md)

## 日常操作

按 **J** 打开动作轮盘，可在 Minecraft 控制设置中改绑；F5 使用原版视角切换。

- J 轮盘右上角齿轮或 `/mpaclient settings` 打开玩家模型主页。顶部“客户端／服务端”共用图库布局：客户端浏览私人模型，服务端浏览服务器主动列出的可用伪装模型。
- 点击卡片只预览，加载完成后点“使用模型”应用。按钮与预览区同步区分“预览”“等待确认”“当前使用”；服务端必须收到匹配的请求结果与本人绑定才算应用成功。客户端应用为仅本机外观并撤回当前私人分享，保留玩家／装备显隐、缩放和 XYZ；服务端发送 `/meplayeractions disguise <ID> [参数]`，由服务器校验权限并确认伪装。
- 卡片右上角可收藏模型。客户端卡片左上角云朵与左栏“上传分享”会**使用所选模型并主动上传分享**；分享成功与服务器保存完成分别显示。“已上传”查看服务器保存的本人模型列表，重连后重新同步；本地文件缺失或变化时会注明，不能冒充原上传内容使用。已保存条目的云朵可打开删除确认，等待服务器完成后更新列表；删除服务器资源不会删除本地文件。
- 服务端卡片复用云朵显示资源状态：绿色勾表示已缓存，蓝色勾表示本机资源已就绪但磁盘缓存尚未确认，蓝色向下箭头表示资源可用但待缓存，黄色省略号表示正在接收或校验，红色感叹号表示资源不可用，灰色圆点表示尚未确认。点击云朵查看状态，不单独申请下载。
- 图库使用居中的 5×2 卡片布局；小窗口减少行列，显示尺寸由 Minecraft GUI 缩放设置控制。
- 两个图库的信息图标打开对应简明教程，说明导入、使用、分享、存档管理或服务器伪装与客户端接管。
- 轮盘可悬停后松开 J、点击或按 1–8 选择。普通区域滚轮切页；打开作者配置后，右侧面板内滚轮滚动表单。CLIENT 中心切换动作锁定，SERVER 中心停止手动动作。保持轮盘打开在主页齿轮设置中调整。
- 轮盘左侧“解除私人伪装”关闭私人外观并保留配置。“解除服务器伪装”发送固定 `/meplayeractions undisguise`，等待服务器权限检查和解绑确认；外部原生模型只结束 MPA 接管。关闭渲染仍可使用解除入口。

默认已开启**服务器伪装的客户端渲染接管**，无需先启用私人模型。私人外观初始未启用，选用后默认仅自己可见。SERVER 动作需有效连接、本人服务器状态和下发动作目录；**关闭客户端渲染仍可用 SERVER 轮盘与 stop**。CLIENT 显示作者定义的额外动作与分类，只在本机播放；需要改变真实姿态时使用服务器 `/meplayeractions pose`。

服务器动作优先显示配置的名称，没有名称时显示原始动画 ID，方便区分作者动作。轮盘名称与播放提示来自服务器动作目录，不依赖是否下载或接管模型。

## 显示来源与三个显隐

服务端图库使用模型需要服务器支持模型目录，并授予 `mact.use` 与 `mact.disguise` 权限；目录来自 ModelEngine 已注册的有效模型 ID，最多 4096 条，与 `/meg disguise` 使用同一模型来源。MPA 配置或资源目录中没有对应模型，不影响服务器伪装。浏览不会下载全部模型，未取得资产的卡片先显示名称；使用后有可用资源才授权下发，已收到的模型可以预览。目录与权限按后台周期刷新，默认在 20 TPS 下约 7 秒内更新，伪装命令仍即时检查权限。

未连接模型服务时显示“离线模式”，仍展示本机已验证缓存供预览。在线但不在当前授权目录的缓存同样只能预览；关联模型 ID 的缓存可提前保存外观参数。未关联 ID 的历史缓存以短 hash 标识，不能配置服务器参数或发送伪装命令。缓存不能代替当次目录与权限，不会被标为“当前使用”。

左侧预览和云朵提示分别说明**服务器资源、客户端资源、本地接管**。服务器会报告资源取自 MPA models 目录、插件内置资源或 ModelEngine 蓝图，以及资源准备、缺失或校验失败的原因；目录中存在文件并不等于校验通过。仅浏览尚未绑定的模型时，未获服务器确认的资源显示“尚未确认”。已缓存、可预览或正在使用服务器伪装，都不等于接管已启动；接管须完成本次授权、解析、纹理准备和服务器确认。资源不可用或关闭客户端渲染时保持服务器显示。

服务器伪装与私人外观互斥，最多一个模型处于“当前使用”。开始服务器伪装时暂停私人显示、动作和分享；客户端图库仍可浏览，但须先解除服务器伪装才能使用私人模型或上传分享。解除服务器伪装后显示原版人物，保存的模型、纹理和参数保留，私人模型须手动重新启用。切换图库标签只切换浏览来源，不改变当前使用模型。

主页与详情的三个按钮立即保存、各自独立：

| 按钮 / 字段 | 没有本人服务器伪装时 | 本人服务器伪装期间 |
| --- | --- | --- |
| 玩家隐藏／显示：`hideVanillaPlayer` | 控制原版人物，保留伪装与主副手物品 | 沿服务器隐藏规则，按钮禁用 |
| 装备隐藏／显示：`hideVanillaEquipment` | 控制原版盔甲、头戴物、披风、鞘翅；不控制作者自带衣物或手持物品 | 强制隐藏原版装备，按钮禁用 |
| 伪装显示／隐藏：`showSelf` | 只控制本人的伪装几何，脚本与物理继续运行 | 同样只控制本人客户端模型，不能扩大服务器观看许可 |

玩家显示时由原版人物绘制装备；玩家隐藏而装备显示时，使用模型可用挂点绘制装备。隐藏伪装不会取消已开启的装备显示。渲染总开关 `enabled` 位于主页齿轮设置中：关闭后恢复服务器／原版显示，保留三个显隐、私人配置和服务器动作连接。

第一人称不画本人的完整身体。私人 YSM 有 `arm/fp_arm` 组件时，原生空手或地图左右手绘制入口使用作者手臂；普通方块、武器及使用物品保留原版持物路径。伪装隐藏时不画作者手臂；玩家显示可回退原版手臂，玩家隐藏则隐藏该原生手臂入口，物品路径保留。

## 文件与导入

服务端图库的文件夹按钮打开**本机接收缓存目录**，并非服务器 `plugins/`。缓存存在只表示已下载，使用仍需服务器授权。

以下路径均相对于**当前 Minecraft 实例**，与服务器 `plugins/MEPlayerActions/config.yml` 分开：

| 路径 | 用途 |
| --- | --- |
| `config/meplayeractions-client.json` | 本人设置、模型 profile、收藏与轮盘记忆 |
| `config/meplayeractions/models/` | 私人 `.bbmodel`、YSM 文件夹、ZIP 或公开自包含 `.ysm`；图库“文件夹”打开目录，“刷新”重新扫描／解码 |
| `config/meplayeractions/cache/` | 服务器授权模型的 SHA-256 缓存；不会自动加入私人图库 |

图库按内置、YSM 与 BBModel 来源分组，显示专用目录内有效模型和真实 YSM 子目录；各目录页码分别记忆，搜索可递归查找。它不提供任意文件系统浏览，也不会因浏览触发私人上传。

独立 BBModel 用 `local:文件名.bbmodel`，仅限目录根部单文件；YSM 用 `ysm:相对路径`，可含安全子目录。ID 最长 128 字符、最多 9 段；禁止绝对路径、反斜线、空段、首尾空白、点号开头、`..`、控制字符及非法路径字符。普通文件名可含空格，建议从图库或 Tab 补全获取 ID。

内置 ID：`openysm_default`、CC0 原始玩家皮肤模型 `openysm_alex`／`openysm_steve`，以及 `wine_fox_01_taisho_maid`、`wine_fox_02_new_year`、`wine_fox_03_astronaut`。酒狐资产采用 [CC BY-NC-SA 4.0](../THIRD_PARTY_NOTICES.md#openysm-wine-fox-model-assets-cc-by-nc-sa-40)，仅供非商用，分发／改编须保留署名与相同许可。服务器 `ysm_01_jk`／`ysm_02_jk` 不内置，须由服务器授权同步或自行私人导入。

本地 YSM 原始输入、展开资源、转换结果分别限 64 MiB；独立 BBModel 原文件限 8 MiB，声明的目录内 PNG 伴随资源及转换后资产分别限 64 MiB。私人分享归档和展开资源限 8 MiB，BBModel 的原生转换派生资产另限 64 MiB，协商可降低；超过分享预算不取消本地加载。文件、图像、几何和脚本各有独立预算，格式与材质要求见 [YSM 支持范围](YSM_COMPATIBILITY.md)。

服务器模型缓存离服后保留，最多 128 MiB／512 个有效文件，按最近使用裁剪。使用缓存仍需取得**当次绑定**确认。资源重载期间等待纹理重新准备；断线／世界切换清理当前绑定和下载授权，保留磁盘缓存。服务器推送不依赖私人分享开关，详见 [模型同步与部署](MODEL_DELIVERY.md)。

## 本地外观与私人分享

客户端“使用模型”仅本机显示，云朵“上传分享”才使用并上传；再次点“使用模型”撤回当前分享。私人分享与服务端 ME 伪装独立，一次发布一个正在使用的私人模型。“已上传”来自服务器的本人缓存目录，不表示多个模型同时分享；缓存受服务器容量与条目上限约束，删除或裁剪后列表会同步更新。

`privateSyncEnabled` 默认关闭。分享需要服务端开启 `client-sync.enabled` 与 `client-sync.private-models.enabled`，并授予发布者 `mact.private.upload`、观看者 `mact.private.view`（权限默认均为 `false`，OP 也需显式授予）。观看者安装支持的客户端即可被动接收，无需开启自己的分享开关；原版观看者仍看到原版玩家。关闭分享或私人外观撤回展示，保留本地内容。

`.ysm` 上传保留模型、动画、控制器、函数、作者配置、纹理、声音与必要资源；`.bbmodel` 保留原模型、内嵌贴图和声明的目录内 PNG。本地与观看端使用同一转换链，不读取编辑器绝对路径或下载外部 URL。皮肤、作者参数、radio、额外动作和允许的原生事件可同步；位置复用原版玩家同步，物理与查询缓存由各客户端维护。

本人有服务器伪装时，私人模型使用与分享入口禁用；解除后须手动选择私人模型重新使用或分享。暂停、上传失败或撤权不删除模型文件和参数。私人中继可在 Paper 1.21.11／Java 21 运行同一服务端 JAR，无需 ModelEngine 或服务器资源包；使用独立 `meplayeractions:private` v1，不与原 OpenYSM 网络协议互通。

私人观看者只使用原版已经同步的玩家状态；食物、经验、完整效果等级和移动输入不额外广播，未提供的查询使用缺省／原版远端字段（例如食物 20）。本人本地使用真实状态，依赖未同步字段的模型可能与观看者表现不同，详见 [状态与渲染规则](YSM_COMPATIBILITY.md#状态与渲染规则)。

状态栏显示准备、等待授权、上传进度、待校验、已分享或失败原因。发布成功以服务器确认为准，资源命中缓存也需本次授权。服务器忙或负载保护时按提示稍后重试；模型无效、复杂度超限或失去权限时先修正原因，不自动反复上传。失败不删除本地文件，不代表服务器已删除旧存档。配置、预算与缓存目录见 [模型部署](MODEL_DELIVERY.md)，服务器限额见 [资源保护](SERVER_RESOURCE_PROTECTION.md)，同步规则见 [客户端协议](CLIENT_PROTOCOL.md)。

## 默认配置与保存

### 服务端模型外观设置

服务端图库选中模型后，点击“外观设置”配置命令参数。每个模型 ID 在本机分别保存，最多 32 份；留空继承服务器默认值。非默认项有黄色修改标记和单项“重置”，另可重置全部。重置只清空草稿中的相应参数，仍需保存后再应用，不影响其他模型或私人外观配置。

| 参数 | 可选值 |
| --- | --- |
| `scale` | 0.05–8 |
| `hide-self` / `show-self` | `true` / `false`，控制原版人物隐藏及本人观看 |
| `view-distance` | 0.1–256 格 |
| `max-viewers` | 0–1000 名其他观看者 |
| `delay` | 0–20 tick，服务器 ME 视觉延迟 |
| `effect` | `slowness:等级[:秒数]`，等级 1–256，指定时长 1–86400 秒；留空不请求效果，服务器另检查效果权限 |

“保存设置”只保存本机草稿；返回点击“使用模型”，或对当前模型点击“应用设置”，才发送带参数的伪装命令。服务器拒绝或确认超时不会显示新参数已生效。

### 本机配置文件

文件不存在时使用默认值，菜单／命令触发保存后写入；已有有效设置不会被默认值覆盖。菜单应用即时生效。手动编辑时先关闭游戏、重启读取，没有 `/mpaclient reload`。

```json
{
  "enabled": true,
  "showSelf": true,
  "hideVanillaPlayer": true,
  "hideVanillaEquipment": true,
  "interpolationTicks": 2,
  "followServerTimeline": false,
  "showModelIds": false,
  "defaultHeaddress": true,
  "defaultBlueTexture": false,
  "localActionLocked": false,
  "privateSyncEnabled": false,
  "privateAppearancePaused": false,
  "favorites": [],
  "modelProfiles": {},
  "serverDisguiseProfiles": {},
  "wheelPreferences": {
    "source": "client",
    "clientPage": 0,
    "serverPage": 0,
    "keepOpen": false
  },
  "localAppearance": {
    "enabled": false,
    "modelId": "openysm_default",
    "scale": 1.0,
    "offsetX": 0.0,
    "offsetY": 0.0,
    "offsetZ": 0.0
  }
}
```

| 字段 | 类型与含义 |
| --- | --- |
| `enabled`、`showSelf`、`hideVanillaPlayer`、`hideVanillaEquipment` | 布尔；对应总渲染与三个显隐，默认见上文 |
| `followServerTimeline` | 布尔，默认 `false`：普通动作本地计算，服务器手动动作和许可仍生效；`true` 仅改用服务器动画时间线。所有模式的位置、角度和插值均复用原版本帧渲染状态；服务器轨迹只供诊断。仅 JSON 配置，改变后重握手；私人模型使用本地动画 |
| `interpolationTicks` | 整数，默认 `2`，限制 `0–6`；服务器动画时间线的采样缓冲，不增加玩家位置延迟 |
| `showModelIds` | 布尔，默认 `false`；图库“ID”切换名称／ID，标题最多两行 |
| `defaultHeaddress`、`defaultBlueTexture` | 布尔，默认 `true`／`false`；仅 `openysm_default` 的红蝴蝶结／蓝色皮肤兼容默认，已保存作者变量／皮肤优先；快捷按钮即时保存 |
| `localActionLocked` | 布尔，默认 `false`；移动是否继续私人额外动作，CLIENT 轮盘中心或主页设置调整，不改变真实姿态 |
| `privateSyncEnabled` | 布尔，默认 `false`；显式私人分享选择，须服务器允许，关闭可随时撤回 |
| `privateAppearancePaused` | 布尔，默认 `false`；服务器伪装暂停私人外观的持久标记。服务器伪装结束后仍保持暂停，显式重新使用私人模型才清除 |
| `favorites` | 有效私人 ID 的字符串数组，最多 64 项；卡片右上角收藏保存，不改变模型 |
| `wheelPreferences` | `source` 为 `client`／`server`；两种来源页码分别为 `0–127`，显示时限制至实际页数；`keepOpen` 默认 `false`。记忆显式选择，但新伪装实例仍自动 SERVER |
| `localAppearance` | `enabled` 布尔；有效 `modelId` 字符串；`scale` 有限数字 `0.05–8`；XYZ 有限数字各 `-32–32` 方块，沿世界轴，Y 正值向上。用户缩放 `1` 保留作者初始比例 |
| `modelProfiles` | 按私人模型 ID 保存 `textureId`、作者 `variables` 与 `radioSelections`，见下文 |
| `serverDisguiseProfiles` | 按服务端模型 ID 保存上表中的可选命令参数，最多 32 份；默认项省略。不保存服务器授权或当前伪装实例 |

配置须小于 64 KiB。私人段缺字段、类型／范围／ID 无效时，回到未启用默认值。轮盘容器无效重置轮盘段，单字段无效使用该字段默认值。读取或保存失败会记录日志；手动修改前建议保留配置副本。

服务器发现／校验频率在服务器 YAML 中设置，见 [性能配置](PERFORMANCE.md)。

### 作者配置、预览与恢复

“外观设置”中的本地启停、三个显隐、缩放和 XYZ 是草稿；“保存”应用并留在页面，“保存并预览”启用私人外观、恢复伪装显示并切第三人称。默认模型头饰／皮肤快捷按钮立即保存。作者配置读取自己的 `config_forms`：独立页 checkbox／range／radio 点击“应用并保存”才提交，J 轮盘关联表单按交互执行作者脚本并保存；皮肤按钮依作者纹理列表切换且立即保存，无需先启用模型。滑条／数值输入使用作者步长，长表单滚动裁切，组名／标题／说明／选项读取作者语言属性。

`modelProfiles` 最多 32 个模型，每模型最多 128 个作者变量、64 个 radio 选择；缺省用作者默认，无效整段忽略，保存失败保留原配置。数字变量须有限、绝对值不超过 1,000,000；`variable.roaming.<name>` 每模型最多 64 项、名称最多 32 字符。模型在本人世界中修改的 roaming 变量会保存，预览与远端不会回写；控制器、物理和查询缓存不保存。重新选择、进入世界和重启恢复已保存皮肤／变量／radio。

“重置模型配置”只重置当前模型皮肤／作者变量／radio。“恢复默认”还恢复私人默认模型、缩放 `1`、XYZ `0`、默认皮肤／蝴蝶结并关闭私人外观，清理当前及默认模型 profile；不重置总渲染、三个显隐、轨迹、收藏或其他 profile。`/mpaclient local reset` 只重置 `localAppearance`。

## 客户端命令

命令需连接世界；模型／动作 ID 支持 Tab 补全，`local model` 接受子命令后的完整 ID（可含普通空格）。

| 命令 | 作用 |
| --- | --- |
| `/mpaclient`、`/mpaclient settings`、`/mpaclient local` | 打开同一主页，不隐式选用私人模型 |
| `/mpaclient status` | 连接、资产／同步阶段、hash 前 12 位、来源与错误、即时／轨迹、三个显隐、私人加载／分享、已发生查询降级的名称／次数／实际默认值 |
| `/mpaclient toggle` | 保存总渲染开关，重新开启等待资源／接管就绪 |
| `/mpaclient local model <ID>` | 选择并启用私人模型、开启总渲染，保留 XYZ／缩放及已有 `showSelf` |
| `/mpaclient local play <ID>`、`local stop` | 播放／停止私人手动动作，不请求服务器动作 |
| `/mpaclient local off`、`local reset` | 关闭私人外观且保留参数／恢复私人默认配置并关闭 |
| `/mpaclient preview <ID>`、`preview off` | 临时第三人称预览／停止：需在世界中且无本人服务器绑定，不保存私人选择或主动下载。服务器示例需 MPA 资源包索引；日常选择使用图库 |

## 排障

| 现象 | 检查 |
| --- | --- |
| 渲染开启但本人看不见 | F5 切第三人称，启用“伪装显示”，再查加载与服务器本人观看许可；玩家／装备按钮不隐藏伪装 |
| 仍显示 ME／接管加载中 | `/mpaclient status` 与管理员 `/meplayeractions status player <玩家名>` 查资产与观看许可；全局 `/meplayeractions status` 查预算或负载保护。未就绪时保留服务器模型，默认主动推送无需资源包索引 |
| 私人模型／编辑暂时不见 | 本人服务器伪装期间暂停私人使用与分享，可继续浏览、编辑草稿；解除后需手动重新使用私人模型，保存的模型及参数仍保留 |
| 装备缺失或作者衣物仍在 | 私人外观默认装备隐藏，可独立显示；服务器伪装强制隐藏。作者自带几何属于伪装，主副手物品保留 |
| 点卡片后世界没变 | 点击仅预览，加载成功后“使用模型”或保存启用 |
| 无服务器动作／分享按钮不可用 | 单机／无插件服务器用 CLIENT 本地动作；分享需服务器支持、开关与上传权限，服务器伪装时暂停私人分享。观看者只需观看权限；查看页面状态或 `status` |
| 导入不出现／失败 | 检查专用目录、有效 ID、普通文件／目录、自包含资源与预算，点击刷新；链接、外部路径、需额外密钥缓存和不支持几何会拒绝 |
| 加载成功但动作与参考项目不同 | 核对 [支持矩阵](YSM_COMPATIBILITY.md) 的查询、控制器、locator 和外部联动；未绑定查询可能为 `0`，显式 `null` 用作者默认表达式；status 只记录实际发生的降级 |
| 默认皮肤／头饰快捷项不见 | 只用于 `openysm_default`；其他模型用自身“作者配置／皮肤”或轮盘齿轮 |
| 重启未恢复设置 | 确认当前实例配置，关游戏再编辑重启；查类型／范围／日志及 64 KiB 限制 |

配置实现见 [ClientOptions](../client/src/main/java/com/simmc/meplayeractions/client/ClientOptions.java) 与 [LocalAppearanceSettings](../client/src/main/java/com/simmc/meplayeractions/client/LocalAppearanceSettings.java)；界面与渲染源码入口见 [开发导航](../CONTRIBUTING.md)。
